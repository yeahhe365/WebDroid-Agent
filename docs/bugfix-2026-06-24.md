## Security fixes

1. **Shell argument escaping utility** — `src/adapters/shellEscape.ts` (`escapeShellArg`),
   covered by `src/adapters/shellEscape.test.ts`.
2. **`open_url` command injection** — URL is escaped before reaching the device shell
   (`src/adapters/inputCommands.ts`), covered in `src/adapters/inputCommands.test.ts`.
3. **`set_clipboard` command injection** — clipboard text is escaped through the shared
   `buildSetClipboardCommand` builder (`src/adapters/inputCommands.ts`, used by
   `src/adapters/webAdbBackend.ts`). Regression tests were added later, in
   `src/adapters/inputCommands.test.ts` ("buildSetClipboardCommand security").
4. **`launch` package-name validation** — package names must match the Android package
   pattern before use (`src/lib/actionValidation.ts`), covered by
   `src/lib/actionValidation.packageName.test.ts`.
5. **`escapeInputText` backslash escaping** — backslashes are escaped as well as
   whitespace (`src/adapters/adbKeyboard.ts`), covered by
   `src/adapters/inputCommands.test.ts` and `src/adapters/adapterUtilities.test.ts`.

## Agent loop fixes

6. **Abort signal propagation into the final response** — `recordAgentFinalResponse`
   receives the pending-step abort signal (`src/hooks/useAgentRunController.ts`), and
   `stopCurrentRun` aborts both the run and the pending-step controllers. Regression
   test added later: `src/hooks/useAgentRunController.test.tsx`
   ("aborts an in-flight manual step when the run is stopped").
7. **Queue flush race** — queued composer messages flush behind a mutex ref instead of
   re-entrant effects (`src/hooks/useAgentRunController.ts`), covered by
   `useAgentRunController.test.tsx` ("queues composer submissions while busy…").
8. **Concurrent `runTask` guard** — an in-flight ref prevents overlapping task runs
   (`src/hooks/useBusyTask.ts`).
9. **Pending step cleared on thread switch** — `setPendingStep(null)` runs on new chat,
   history select, history delete, and history clear (`src/App.tsx`).
10. **Separate failure counters** — model errors and execution failures are counted
    independently so model retries no longer consume execution recovery budget
    (`src/lib/agent.ts`).

## Safety policy fixes

11. **URI scheme allowlist in `open_url`** — only approved schemes pass validation
    (`src/lib/actionValidation.ts`), covered by `src/lib/actionValidation.security.test.ts`.
12. **Clipboard control-character validation** — control characters are rejected
    (`src/lib/actionValidation.ts`), covered by `actionValidation.security.test.ts`.
13. **NFKC normalization for safety patterns** — action text is normalized before
    matching, defeating full-width and styled-Unicode bypasses
    (`src/lib/actionSafetyPolicy.ts`), covered by
    `src/lib/actionSafetyPolicy.normalization.test.ts`.
14. **Composite actions evaluate child safety, `type_secret` is mutating** —
    composite actions recurse through per-child safety evaluation, and `type_secret`
    is listed in `MUTATING_ACTIONS` (`src/lib/actionSafetyPolicy.ts`,
    `src/lib/toolRegistry.ts`).

## UI fixes

15. **Thread delete confirmation** — `window.confirm` guard in
    `src/components/ChatHistorySidebar.tsx`.
16. **Sensitive-dialog focus trap** — auto-focus, Escape handling, and Tab/Shift+Tab
    cycling inside the dialog (`src/components/SensitiveActionDialog.tsx`), covered by
    `src/components/SensitiveActionDialog.test.tsx` ("traps Tab focus inside the dialog").
17. **Stack-managed body scroll lock** — a shared lock stack for `overflow` and
    `overscroll-behavior` (`src/hooks/useBodyOverflow.ts`), consumed by the phone
    fullscreen preview, screenshot lightbox, installed-apps dialog, and App modal
    overlays. Covered by `src/hooks/useBodyOverflow.test.ts`.
18. **Topbar status ellipsis** — nested `.status-label` span keeps long app names
    truncating without breaking the layout (`src/components/AppTopbar.tsx`,
    `src/styles/layout.css`).
19. **Debounced history search** — 300 ms debounce before filtering
    (`src/components/ChatHistorySidebar.tsx`).

## Deliberate deviation from the plan

- The plan's "busy guard on Enter submit" was implemented in `0230bbf` and then
  intentionally removed in `bca7168`: the composer now queues messages while a run is
  active (`src/components/ChatPanel.tsx`, `useAgentRunController.ts`). Do not restore
  the hard guard; it would break queueing.

## Still open

  → sensitive action) has no recorded run; it needs a physical Android device.
- `App.tsx` and `InstalledAppsSection.tsx` previously wrote `document.body.style.overflow`
  directly; both now use `useBodyOverflow`. `config-rail.css` and the dead
  `ConfigRail` / `DirectCommandsSection` components were removed in the same cleanup.
